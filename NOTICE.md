# Hermes Pet Notice

Hermes Pet is distributed as a Hermes Agent companion/connector and is intended
to remain removable without modifying an installed upstream Hermes command.

This repository is derived from the MIT-licensed Hermes Agent project by
Nous Research. The upstream license is preserved in `LICENSE`.

Hermes Pet's optional artwork import workflow supports the public
[Codex Pet Share](https://codex-pet-share.pages.dev/) catalog. Thanks to the
Codex Pet Share maintainers and community artists for making animated companion
pet artwork discoverable. Imported artwork should retain its title and author
metadata when shown in demos, screenshots, or downstream distributions.

The public macOS MVP binds only to `127.0.0.1` by default and does not require
network forwarding tools.
